Group: <3>  |  Members: Abenojar, Agatep, Lumbag, Linde

# Purpose
Small stores lose money when supplies expire unnoticed or run out of stock.
This command-line app records supplies, stock counts, and expiration dates in a
SQLite database, shows expired, expiring-soon, and low-stock items, and
produces analytics and charts to show losses and usage.

# Features
- Add, view, search, update, and delete supplies
- Record stock in / out / discard
- Expiration alerts and low-stock flags
- Analytics report and charts
